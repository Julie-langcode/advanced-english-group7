## Как устроен сайт

```
index.html                 главная: список уроков, оценивание, правила
assets/config.js           настройки: группа, ссылка на Google-таблицу, доска Miro
assets/course.js           список уроков модуля (статус ready / soon)
assets/style.css           оформление
assets/engine.js           движок уроков (обычно не трогаем)
assets/audio/              аудиофайлы
lessons/01-cities/         урок 1: index.html + lesson.js (всё содержание урока)
lessons/02-urban-renewal/  урок 2
lessons/_template/         заготовка для нового урока
apps-script/Code.gs        скрипт для Google-таблицы с результатами
```

## Режим преподавателя

Откройте любой урок с `#teacher` в конце адреса (например `…/lessons/01-cities/#teacher`) — на этом устройстве появится кнопка **Teacher notes** с методическими заметками на русском. Студенты её не видят. Выключить: открыть с `#student`.

## Связка с Google-таблицей

Сайт уже подключён к той же таблице результатов, что и группа 6: в каждой строке есть колонка *Group*, поэтому группы не смешиваются (удобно отфильтровать). Если нужна отдельная таблица для группы 7 — повторите шаги ниже в новой таблице и замените `SHEET_ID` в скрипте и `sheetEndpoint` в `assets/config.js`.

### Как подключить таблицу (один раз, ~5 минут)

1. Откройте таблицу результатов → **Расширения → Apps Script**.
2. Удалите всё в редакторе, вставьте содержимое файла `apps-script/Code.gs`, сохраните.
3. Вверху выберите функцию `setup` → **Выполнить** → разрешите доступ к таблице. В таблице появятся листы *Checks*, *Tasks*, *Submissions*.
4. **Начать развёртывание → Новое развёртывание → Тип: веб-приложение.**
   *Запуск от имени:* Я · *Доступ:* Все (Anyone). Нажмите «Развернуть», скопируйте URL, который оканчивается на `/exec`.
5. На GitHub откройте `assets/config.js` → карандаш (Edit) → вставьте URL в `sheetEndpoint: ''` между кавычками → **Commit changes**. Через 1–2 минуты сайт обновится.

Что приходит в таблицу:
- **Checks** — каждая проверка упражнения: студент, урок, упражнение, счёт, ответы.
- **Tasks** — открытые задания, которые студент отправил кнопкой «Send to teacher» (например, бюджет и питч Oldbury).
- **Submissions** — полный текст работы за урок по кнопке «Send my work».

Скрипт работает от вашего имени, поэтому доступ к самой таблице можно (и лучше) закрыть: «Доступ ограничен», только вы.

## Как добавить новый урок

1. Скопируйте папку `lessons/_template` и переименуйте, например, в `lessons/03-culture-and-identity`.
2. Заполните `lesson.js` по образцу уроков 1 и 2 (типы заданий: `gap`, `match`, `pick`, `stress`, `open`, `budget`). В `index.html` поменяйте только `<title>`.
3. В `assets/course.js` у этого урока поставьте `status: 'ready'` и проверьте, что `slug` совпадает с названием папки.
4. Аудио положите в `assets/audio/` и добавьте блок `{ type: 'audio', src: '../../assets/audio/имя.mp3', … }`.

Можно попросить Claude: «добавь урок 3 по плану группы 7» — он сделает это в этом репозитории.
